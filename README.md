# Express Transportes

Site estático do projeto "Express Transportes" — pronto para publicar com GitHub Pages.

## O que eu implementei
- SEO básico: meta tags e Open Graph no `index.html`.
- Formulário de contato integrado com FormSubmit (envia para comercialexpresstransportes@gmail.com) e redirect para `thank-you.html`.
- Páginas adicionais: `404.html` e `thank-you.html`.
- Favicon (`favicon.svg`) e versão minificada de CSS/JS (`style.min.css`, `script.min.js`).
- `sitemap.xml` e `robots.txt`.

## Como publicar
1. Vá a Settings → Pages no repositório e escolha:
   - Branch: `main`
   - Folder: `/ (root)`
2. Salve. Em alguns minutos o site estará disponível em: `https://ManuelHBango.github.io/Express-Transportes/`.

## Notas e recomendações
- FormSubmit: o serviço funciona sem backend, mas requer que o email receptor confirme o primeiro envio que chegará (verifique a caixa do email `comercialexpresstransportes@gmail.com`).
- Se quiser um domínio próprio, diga o domínio e eu crio `CNAME` e instruções DNS.
- Posso otimizar imagens e adicionar versões WebP posteriormente; por agora mantive os arquivos originais.
